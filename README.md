# Buka Registration Prototype

This is the first frontend screen for the Buka web application.

## Tech
- React
- TypeScript
- Vite
- CSS

## Run in VS Code

1. Open this folder in VS Code.
2. Open the terminal.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local URL shown by Vite, usually:

```text
http://localhost:5173
```

## Current functionality

- Responsive registration page
- Full name, email and phone fields
- Lesotho +266 phone prefix
- Password + confirmation
- Show/hide passwords
- Form validation
- Terms checkbox
- Prototype Google sign-up button
- Successful registration screen
- Cute Buka branding

## Important

This is frontend-only for now. It does NOT save users to a database or provide real authentication yet.

Next step: connect registration to the Buka backend/API, password hashing, email/OTP verification, and then business onboarding.
